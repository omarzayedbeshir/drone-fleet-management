## Reproduce

From the repository root with Docker permissions:

```sh
docker compose up -d --wait database
./backend/scripts/migrate.sh
./backend/scripts/migrate.sh
docker compose exec -T database sh -c 'exec psql -X -v ON_ERROR_STOP=1 -U "$POSTGRES_USER" -d "$POSTGRES_DB"' < backend/tests/schema.sql
```

Then export the actual backend configuration, using a development/test database:

```sh
cd backend
set -a
. ./.env
set +a
TEST_DATABASE_URL="$DATABASE_URL" go test -race ./internal/httpapi -run Integration -count=1
go test -race ./...
go vet ./...
go build ./...
```

Go integration tests create/drop private schemas; they do not use existing application drones. See [ARDUPILOT.md](../../backend/ARDUPILOT.md#verification) for the opt-in live SITL tests. Run one consumer per SITL TCP serial endpoint at a time. Without the corresponding environment variables, database and live SITL tests are skipped; a skipped test is not new integration evidence.

## Decision and remaining risk

Keep Go + TimescaleDB and the [single-node design](../ARCHITECTURE.md). The working adapter demonstrates protocol feasibility. Pairing/review of the first adapter and agreement on the shared raw-record/stage boundary still need Seif/Ali and Hamza's review; a passing test cannot establish team agreement.

This spike does not prove production sizing, uptime, backup recovery, the 1,000-drone/1-message-per-second load target, DJI access, or the final staged pipeline. Battery-cycle totals are preserved from the database rather than measured by SITL. Retention/compression, batching, and downstream events remain Ziad's scope. Leave the Sprint 2 load test and teammate-owned pipeline work with their owners.
